# 言简 · Agent 开发提示词

把简单想法整理成可直接交给开发 Agent 的任务提示词，使用 DeepSeek 官方 API。需要 Python 3.10 或更高版本，无第三方运行依赖。

## 启动

双击 `start.bat`，保持服务窗口打开，访问 http://127.0.0.1:8765 。也可以运行 `python server.py`。

首次使用点击「连接设置」，输入自己的 DeepSeek API 密钥。密钥保存在本项目的 `.env` 文件，也可通过 `DEEPSEEK_API_KEY` 环境变量提供（优先于文件）。`.env` 已加入 Git 忽略规则，不要分享这个文件。

## 使用流程

1. 用一句话描述想法，例如“我想做一个个人记账工具，记录收支，按类别统计每月花销”。
2. 点击「生成开发提示词」或按 Ctrl+Enter。项目类型默认自动判断；详细程度默认标准，无须先填写完整需求。
3. 工具整理目标、最小功能范围、使用流程、实现约束、验收标准和交付要求。
4. 点击「复制给 Agent」，粘贴到你使用的开发 Agent，让它在对应项目中开发。

已有项目、技术栈和个人偏好可以填入「补充已有项目或偏好」。普通未知项以可调整的默认建议处理；真正影响实现的关键未知信息会写入任务提示词，要求 Agent 检查项目后再按需确认。工具只生成任务提示词，开发在用户选择的 Agent 中进行。

支持编辑结果、复制、导出 Markdown、继续优化与最近 20 条历史恢复。历史保存在当前浏览器，可在历史窗口清空。模型列表由账号的 `/models` 接口加载。旧版历史记录仍可查看。

输入和补充信息仅在生成时发送至 DeepSeek；API 调用按 DeepSeek 账号实际用量计费。错误提示覆盖无效密钥、余额不足、限流及连接超时。单次最多输入 12000 字，补充信息最多 4000 字。

服务只监听本机 `127.0.0.1`。不要直接用于公网部署；本版本没有多用户登录。修改 `.env` 中 `PORT` 可更换端口，重启后访问新端口。环境变量密钥需在系统环境中修改，不能在网页覆盖。

接口文档：https://api-docs.deepseek.com/api/create-chat-completion/ 。
